## Apa itu Scaffdev?

Scaffdev membuatkan **project baru siap jalan dalam hitungan detik** — bukan folder kosong, melainkan starter kit lengkap: tampilan visual yang sudah jadi, struktur folder best-practice, file `.env.example`, dan panduan setup `SETUP.md` yang digenerate otomatis.

> Saat ini template tersedia untuk **Next.js** dan **Laravel**. Framework lain menyusul.

## 🚀 Mulai dalam 10 Detik

Tanpa install apa pun — cukup Node.js v18+, Git, dan koneksi internet:

```bash
# Mode interaktif: pilih kategori → framework → varian
npx scaffdev@latest

# Langsung via slug template
npx scaffdev@latest toko-saya --template=ecommerce-supabase-midtrans-nextjs

# Lalu, untuk Next.js:
cd toko-saya && npm install && cp .env.example .env.local && npm run dev
```

## ✨ Fitur

- 🎨 **Starter kit siap demo** — e-commerce, landing page, portfolio dengan UI yang sudah jadi, bukan halaman kosong.
- 🧩 **Kurasi lokal Indonesia** — Supabase, Midtrans, Xendit, Duitku.
- ⚡ **Satu baris command** — `git clone` + `.env.example` + `SETUP.md` dibuatkan otomatis.
- 🤖 **Asisten AI** — tanya soal CLI, template, setup, dan error langsung di website.
- 📣 **Lapor bug mudah** — form publik, bisa lampirkan gambar bukti.
- 🔍 **Dokumentasi lengkap berbahasa Indonesia** — dari install sampai troubleshooting.
